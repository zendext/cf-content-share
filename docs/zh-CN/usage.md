# 使用方式与 MCP 操作

[English](../en/usage.md) · [文档入口](../../README.zh-CN.md#文档)

## 连接与边界

将支持远程 Streamable HTTP 和 OAuth 的 MCP 客户端连接到 `https://<你的域名>/mcp`，完成浏览器登录，再调用 `describe` 发现目录。服务支持 MCP `2025-11-25` 和 `2025-06-18`；支持的请求版本原样协商，否则返回首选版本，由客户端决定是否接受。具体客户端的登录、刷新和撤销需要在你的部署中验证。

服务只有一位管理者。管理与统计需要认证，公开链接不要求登录。没有管理网页、多用户协作、访问密码、指定访客、自定义短链别名、远程文件导入或回收站。文件正文通过 HTTP 上传，不能把本地路径当作服务端可读取的文件。

## 发现与调用

MCP 仅暴露 `describe` 和 `invoke`。下表是 operation 名称，不是额外的 MCP 工具。先用 `describe` 获取当前参数 Schema，再调用 `invoke`；不要依赖静态文档猜测参数结构。

| Operation | 用途 |
| --- | --- |
| `resource.create_url` | 创建 HTTP/HTTPS 短链 |
| `resource.list` | 分页搜索、筛选资源 |
| `resource.get` | 查询详情、分享地址和当前状态 |
| `resource.update` | 修改标题、描述、标签、短链目标或有效期 |
| `resource.delete` | 永久逻辑删除，查询 KV 与文件清理状态 |
| `upload.authorization` | 复用当前 MCP 登录，取得 HTTP 上传凭据和契约 |
| `operation.list` | 查询处理中或需要处理的操作 |
| `operation.get` | 查询步骤、结果、错误与重试安排 |
| `operation.retry` | 恢复服务端可执行的未完成步骤 |
| `storage.get` | 查询容量限制、已发布、预留和待清理占用 |
| `stats.query` | 汇总、趋势、来源、地区和排行 |
| `stats.samples` | 查询平台实际可返回的访问样本 |

创建请求前持久保存操作 ID 与完整参数。相同 ID 和参数返回原资源；参数不同会被拒绝。网络结果不明时先查询原操作，不能用新 ID 重复创建。HTTP 成功或某一步完成，不等于资源已经可访问；使用结果中的 `accessible`、`unavailable_reason` 和各步骤状态。

## 分享、编辑与搜索

每个资源使用独立的 12 位随机字母数字 ID，统一分享地址为 `https://<域名>/r/<id>`。同名或同摘要文件不会去重；旧 ID 不会分配给其他内容。

短链返回 302 和 `no-store`，可以编辑目标并保留分享地址；创建时不会主动抓取目标页面。图片直接展示，其他文件默认下载。文件发布后不能替换正文、文件名、类型、大小或摘要；新内容需要创建新资源。标题、描述和标签仅用于管理。SVG 按原字节提供，不进行内容清洗。

资源列表默认每页 20 条、最多 100 条，按创建时间倒序，以 ID 作为稳定次序。游标绑定筛选条件，不保证分页期间的数据库快照。关键词在标题、描述和文件名中按连续文字匹配；ASCII 大小写不敏感，`%` 和 `_` 按普通字符处理。标签精确匹配，多个标签要求全部满足；类型、时间和关键词等条件取交集。

## 有效期与删除

创建时省略 `retention_seconds` 表示首次发布后 2592000 秒（30 天），正的安全整数表示自定义时长，显式 `null` 表示永久。等待上传或恢复不消耗新资源的保留时长。

未到期的已发布资源可以修改未来的绝对 UTC Unix 秒 `expires_at`；省略表示不改，`null` 表示永久。相对时间请求应先按用户意图换算并保存绝对时间，重试不重新计时。普通编辑和访问不会延长期限。

已到期资源不能续期或恢复。默认列表不显示已到期、已删除资源，按 ID 仍可查看历史状态；`state=published` 也可能同时为 `accessible=false`。

删除先记录逻辑状态，再传播 KV 更新和清理 R2；每一步分别报告。KV 接受更新不代表所有节点已同步，传播期间仍可能服务旧映射，受原快照最长 24 小时截止约束。到期检查和删除检查先于正文缓存，但无法收回浏览器已有副本。

文件上传及恢复见[文件文档](files.md)，统计口径见[统计文档](analytics.md)。
